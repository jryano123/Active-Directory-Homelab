### Creating Security Groups for Every Department

Created security groups for the IT, HR, and Sales departments and organized them within their corresponding Organizational Units (OUs).

Security groups are used to manage user access and permissions more efficiently. Instead of assigning permissions to each user individually, users can be added to a department's security group and permissions can be assigned to the group. This makes access management easier, especially when managing multiple users.
