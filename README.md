## Tools
Here's a Tools Used list based on everything from this AD lab specifically:

VirtualBox — virtualization platform for running all VMs
Windows Server 2022 (Evaluation) — domain controller OS
Windows 11 (Enterprise Evaluation) — client endpoint OS
Active Directory Domain Services (AD DS) — Windows Server role for directory services
DNS Server (Windows Server role) — name resolution for the domain
Active Directory Users and Computers (ADUC) — console for managing OUs, users, and groups
Group Policy Management Console (GPMC) — for creating and linking GPOs
Group Policy Management Editor — for configuring individual GPO settings
Command Prompt (ipconfig, ping, nslookup, gpupdate, gpresult) — network and policy troubleshooting
